# 실험 방법론

## 통제 조건

- 세 알고리즘은 같은 시나리오, 에이전트 수, 시드, 초기 위치, A* 경로, 반지름, 최고 속도와 안전거리를 사용한다.
- 기본 에이전트 수는 5, 10, 20, 40, 80명이며 조건마다 기본 10회 반복한다.
- 물리 시간 간격은 0.1초, 제한 시간은 60초다.
- 알고리즘 계산 시간은 `perf_counter_ns`로 속도 결정 구간만 측정한다.

## 지표 정의

- Goal Reaching Time(s): 시작부터 목표 반경 0.45m 진입까지의 물리 시간. 실패는 결측값이다.
- Path Length(m): 제어 로봇 위치 변화량의 누적 합.
- Collision Count: 두 원의 반지름 합보다 가까운 상태로 새로 진입한 횟수.
- Safety Distance Violations: 반지름 합과 안전 여유의 합보다 가까운 상태로 새로 진입한 횟수.
- Success Rate: 동일 조건 반복 중 제한 시간 이내 도착한 비율.
- Algorithm Time(ms): 지역 회피 속도 계산에 사용한 실제 벽시계 시간.
- Mean/P95 Time per Step(ms): 스텝별 계산 시간의 평균과 95백분위.
- Robot Stop Time(s): 속력 0.05m/s 미만인 물리 시간.
- Minimum Separation(m): 프레임 사이 선형 이동까지 고려한 최소 중심 거리.

## 해석 제한

Runtime은 운영체제 스케줄링과 Python 실행환경의 영향을 받으므로 동일 장비에서 반복 측정해야 한다. ORCA의 상호 회피 가정은 비협조 작업자 모드에서는 성립하지 않으며, 이때 제어 로봇이 회피 책임 전부를 부담한다. 다른 이동 에이전트는 지정 목적지를 왕복하는 단순 운동 모델이며 서로 간 충돌 회피는 수행하지 않는다.
