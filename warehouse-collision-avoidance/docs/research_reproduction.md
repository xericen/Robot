# 연구 분석 재현 및 한계

본 연구의 원본은 로컬 완료 배치 240회와 별도 예비 배치 18회다. 기존 60회 스윕·18조건 기준 실험·Pygame 사전 타당성 자료는 변경하지 않는다. 240회 주 분석과 보완 30회의 비용을 합산하지 않는다.

## 실행

```bash
cd warehouse-collision-avoidance
python3.12 -m venv .venv
.venv/bin/pip install -r requirements-newton.txt
.venv/bin/python research_pipeline.py --supplement
.venv/bin/python -m pytest -o addopts='' -q
```

기본 원본 경로는 research_data.py의 MAIN/PILOT이다. 별도로 보관된 실제 배치는 --primary <240회배치디렉터리> --pilot <예비18회배치디렉터리>로 지정한다. 원본이 없으면 missing.json만 기록하고 수치를 만들지 않는다. 현재 분석은 results/newton/research/20261117T115115_2ef7f604/에 있다.

완료된 연구를 다시 분석할 때:
```bash
.venv/bin/python research_pipeline.py --output results/newton/research/20261117T115115_2ef7f604 --resume-analysis
```
위 명령은 해당 연구의 파생 표·그림·보고서만 다시 생성한다. 원본 파일은 SHA256으로 전후 검증한다. 기본 실행은 UTC 시각+UUID의 새 디렉터리만 생성한다. 기존 출력 폴더를 지정하면 명시적 --resume-analysis 없이는 거부한다. 보완 실험 중단 시 같은 폴더로 --resume-analysis --supplement를 실행하면 완료된 조건을 건너뛰며, 엔진·알고리즘·맵 소스가 변경되면 재개를 거부한다. 미완료 보관 파일은 삭제하지 않는다.

원본 자체를 다시 측정하려면 controlled_study.py --help의 기존 실행기를 사용한다. 이때도 새 배치 ID로 저장하고 본 연구와 분리한다. 그 명령이 공개 GitHub에서 실행 가능하다는 사실과 로컬 240회 원본이 공개되어 있다는 주장은 다르다.

## 조건과 지표

- R0 제외 n=2/4/8/16, 작업자 전용/혼합 분리, Map1·A*·동적 순찰, 시드42~51, 최대5400프레임.
- 예비 시나리오는 Head-On/Crossing/Narrow Passage, 작업자4명·시드42/43·최대2400프레임이다.
- Dense Traffic은 주 분석 n≥8 부분집합이며 추가 독립 실험으로 세지 않는다.
- 도달은 목표0.25m 이내 및 실제속도0.02m/s 이하. 무충돌·안전 도달의 추가 조건은 원본 result.json과 research_data.audit에서 재검증한다.
- 평균 경로 길이는 실패 포함, 도착 시간은 성공에만 정의한다. 타임아웃을 도착 시간으로 대체하지 않는다.
- Runtime은 newton_warehouse.run의 choose_velocity 호출 바로 앞뒤 perf_counter_ns로 계측한다. 물리·전역 탐색·렌더링·통계는 제외한다.
- 새 프레임 중앙값·P95·정지 시간·LP 내부 카운터는 별도 시드42의30회 계측이다. 과거 미측정 값은 N/A다. 추가 카운터 비용으로 과거 Runtime과 직접 합산하지 않는다.
- 정지 시간은 목표 밖에서 실제 XY속도<0.05m/s인 시간이다. 연속5초 정지는 교착 후보이며 교착 확정이 아니다.
- 표본 평균/중앙값/표준편차/최솟값/최댓값, 시드 전체 군집3000회 부트스트랩95% 구간을 저장한다. 동일 시드 구성과 프레임을 iid로 세지 않는다.
- 짝지은 효과 크기 dz는 시드별 차이 평균을 이용하며 분산0이면 N/A다. n=2의 동일 물리 장면 중복 제거 민감도 분석도 제공한다.
- 충돌은 Newton 강체 접촉, 안전거리 위반은 평면 원형 근사의 별도 지표다. 실제 회전 로봇 외형과 차이가 남는다.

## ORCA 감사

현재 책임100%의 비협조적 순찰 조건이다. 독립 반평면/속도원판 교집합 검사를 통해 A(허용해 존재+출력 위반), B(출력 만족+후속 실제속도 이탈), D(현재 제약에 허용해 없음), E(판단 불충분)를 구분한다. C는 비협조적 이동 조건만으로 인과 확정하지 않는다. 목표/실제 잔차는 같은 과거 제약에 대한 값이므로 B를 단일 제어 오류 원인으로 단정하지 않는다. 기존 로그의 선호속도·제약 생성 순간의 작업자 상태는 N/A이며 후시점 상대 상태라고 표시한다.

## 맵 계측

기존 회전 선반과 기존 A*/Dijkstra/RRT를 그대로 사용한다. 반경0.42m+여유0.35m를 공통 적용한다. 점유율은 선반 면적 합, 보호 중심 통행 영역은0.25m 샘플, 최단 길이는0.5m 보수 격자다. 통행 간격은 START 연결 영역에서 보호 원을 수용하는 선반/벽 경계쌍의 운영적 최소 간격이다. 연속 공간의 전역 최소 통로 폭으로 주장하지 않는다.

## 한계 및 후속 연구

주 분석은 단일 맵10시드, 예비3시나리오는2시드, 보완 계측은1시드다. 여러 조건의 동일 결과도 결과로 보고한다. 맵별 전역 경로 계측54회는 추가 로봇 주행 실험이 아니다. 온라인 재탐색·협조형 인구·정적 ORCA 제약·가속도 제약·독립 시드와 맵 확대는 후속 연구로 분리한다. 원본을 보관한 dirty 작업 공간의 HEAD와 파일별 해시를 기록하며 깨끗한 단일 Robot 커밋의 결과로 단정하지 않는다.

웹의 연구 분석은 dashboard.json에 기록된 실제 파생 CSV 값만 표시한다. 완료 배치가 없으면 빈 상태를 표시하며 가상 자료를 만들지 않는다. 기존 시뮬레이션·18조건 비교·결과 기능은 유지한다.
