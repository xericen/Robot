# Noto Sans KR

출처: https://github.com/google/fonts/tree/main/ofl/notosanskr

NotoSansKR.ttf는 위 배포본의 가변 TTF를 fontTools.varLib.instancer로 wght=400에 고정한 Regular 인스턴스이다. Matplotlib의 가변 가중치 매칭 경고를 피하고 읽기 쉬운 보고서 그래프를 생성한다. SIL Open Font License 1.1 전문은 OFL.txt에 보관한다. plot_newton_results.py가 이 파일을 명시 등록한다.
