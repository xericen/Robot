# 창고 환경의 동적 장애물 밀집도에 따른 자율주행 로봇 충돌 회피 알고리즘 비교 분석

Comparative Analysis of Collision Avoidance Algorithms for Autonomous Mobile Robots under Dynamic Obstacle Density in Warehouse Environments

생성 시각: 2026-11-17T12:27:41.824876+00:00

## 1. Introduction

작업자와 AMR이 혼재하는 창고에서 지역 충돌 회피의 안전성·이동 효율·계산 비용을 비교한다. 목표 도달과 안전 도달을 구분하고 입력 크기에 따른 성능 변화를 검증한다. 기존 완료 실험240회를 주 분석으로 재사용하며 추가 계측은 별도 실행으로 관리했다.

## 2. Related Work

Naive는 본 프로젝트의 현재 거리 기반 감속·반발 기준선이다. 미래 위치를 예측하지 않는다. [Fiorini와 Shiller(1998)](https://www.ariel.ac.il/sites/shiller/papers/fiorini98motion.pdf)의 VO는 상대 운동에서 충돌을 유발하는 속도 집합을 다룬다. 본 구현은 예측 시간3초와74개 후보를 검사하는 표본 기반 방식이다.

[van den Berg 등(2011)의 ORCA](https://gamma-web.iacs.umd.edu/ORCA/)는 상호 책임 분담과 속도 반평면을 사용한다. 현재 작업자·추가 AMR은 비협조적 순찰이어서 R0이 책임100%를 부담한다. 해당 구현을 표준 협조형 ORCA 전체의 성능으로 해석하지 않는다.

창고의 전역 경로는 [Hart·Nilsson·Raphael(1968)](https://ai.stanford.edu/~nilsson/OnlinePubs-Nils/PublishedPapers/astar.pdf)의 A* 개념을 이용한 기존0.5m 격자 탐색을 공통 사용한다. Dijkstra는 같은 격자 최단 길이 검증, RRT는 별도 경로 탐색 계측에 활용했다.

## 3. Methodology

Newton1.7.0/Warp1.19.0 CPU 강체,30Hz 회피 업데이트·프레임당2물리 서브스텝, XPBD8반복이다. R0 반경0.42m, 최대속도1.2m/s, 안전 여유0.35m이며 힘 제어가 목표 속도를 추종한다. 실험은 Map1/A*/동적 순찰, workers/mixed, n=2/4/8/16, 시드42~51,5400프레임 한도다. n은 R0을 제외한다. n=12는 기존 데이터 재사용을 위해 추가하지 않았다. mixed는4번째마다 AMR로 n=2에서 workers와 같은 물리 구성이 된다.

회피 Runtime은 choose_velocity 본문 주변 perf_counter_ns 구간이다. 전역 탐색·물리·렌더링·감사/통계 비용은 제외한다. 기존240회에는 평균/최악만 있어 프레임 중앙값·P95·정지 시간·LP 내부 검사·선호 속도는 N/A다. 30회 단일 시드 보완 계측을 따로 저장했다. 추가 카운터 비용이 포함되므로 새 Runtime을 기존240회와 합치지 않는다.

도달은 목표0.25m 이내 및 실제속력0.02m/s 이하, 무충돌 도달은 도달+바닥 제외 접촉0회, 안전 도달은 무충돌+동적/정적 안전거리 위반0 및 최소 이격 기준이다. 동적 최소 거리는 프레임 상대 이동의 선형 보간, 정적 거리는 끝점XY 거리다. 실제3D 접촉은 Newton 버퍼로 별도 집계한다. 미도달 도착시간은 N/A, 경로 길이와 비용은 실패 실행도 포함한다. 재탐색은 구현상0회다.

통계는 시드 전체를 묶어3000회 군집 부트스트랩한다. 같은 시드의 n·집단·알고리즘 관측을 함께 재표집하여 의존성을 보존한다. 짝지은 차이는 동일 맵/만남/인구/n/시드/scene_hash끼리 A-B로 계산한다. 도착시간 차이는 양쪽 도달 실행만 사용하므로 선택 편향 가능성이 남는다. 효과 크기dz는 시드별 차이 평균/표준편차이며 분산0이면 N/A다. 80개 실행/알고리즘은80개 독립 시드가 아니며 독립 시드 묶음은10개다. 표본2개인 예비 시나리오의 구간은 불확실성이 크다.

## 4. Experiments

주 분석240회와 예비18회를 원본·설정·완료 마커·마지막 실제 물리 상태와 대조했다. 세 알고리즘의80개 논리 조건은 모두 동일 초기 상태 해시이며 누락·중복·설정 불일치가 없다. 과거142개 테스트 기록은 /tmp/newton-enhanced-final-tests.log 및 프로젝트 개발로그에 남아 있으며 이번 테스트는 별도 검증 기록에 보존한다.

Head-On/Crossing/Narrow Passage 비교는 n=4 workers,2시드,2400프레임 예비18회를 쓴다. Dense Traffic은 기존Crossing의 n=8/16·두 집단120행 부분집합이며 새로운 독립120회가 아니다. 서로 다른 시나리오의 인구·예산 차이를 무시한 난이도 순위나 검정은 하지 않는다. 밀집은 본 프로젝트의 경로 주변 충돌 기회 증가를 뜻하며 실제 창고 전역의 보편적 군중 밀도 등급은 아니다.

6개 맵은 동일 시작·목표·반경/여유로 실제 장애물과 기존 탐색기를 사용했다. 장애물 점유는 회전 직사각형 면적의 합, 통행 영역은0.25m 격자의 보호 원형 중심 허용 비율이다. 최소 통로 폭은 START와 연결된 영역에서 보호 반경을 수용하는 선반/벽 경계쌍 간격을0.25m로 샘플링한 운영적 지표다. 연속 기하의 전역 최소 폭이라고 주장하지 않는다. 별도 열의 선택 경로 clearance 직경과도 구분한다. 최단 길이는0.5m의 보수적인8이웃 격자 기준이며 연속 공간 최단 길이가 아니다. RRT는 최단성을 보장하지 않는다.

### ORCA 위반 근거

감사20521프레임: A=0, B=4182, D=4531, E=11808. C는 비협조적 움직임이라는 조건만으로 인과 원인을 확정하지 않았으며 E에 가능한 후보를 별도 표시했다.

독립적2D 원판/반평면 교차 검사는 꼭짓점·경계/원 교점과 내부 후보를 검사했다. 주어진 제약에 허용 속도가 없는D와, 해가 있는데 출력이 어긋난A를 구분한다. 실제 기록에서A 오류는 확인되지 않아 회피 알고리즘을 교체하지 않았다. B는 출력은 제약을 만족하지만 후속 실제 속도가 벗어나는 근거로, 물리 추종·프레임 중 조건 변화가 함께 작용할 수 있다. 기존 preferred velocity와 정확한 제약 생성 시점의 작업자 상태는 N/A로 남기고 상대 위치/속도는 관측 후시점임을 명시했다.

## 6. Discussion

알고리즘별 도달·안전성과 계산 비용의 실제 비교는 위 분자/분모 및 짝지은 차이에 근거한다. 안전 결과는 계산 비용이나 이론적 이름만으로 결정되지 않는다. 가속도/속도 추종 지연·비협조적 순찰·정적 장애물의 지역 속도 제약 부재·교착성 정지와 표본화가 영향을 줄 수 있다. 혼합16개 조건에서는 세 방식 모두 안전 도달0/10이었다. 따라서VO를 모든 조건에서 안전한 방식이라고 결론 내리지 않는다.

현재 구현 기준: Naive O(n), VO O(Kn), K=74; ORCA 제약생성O(n)·순차 투영 최악O(n²). 모든 ORCA 구현의 일반적인 평균/최악 복잡도를 의미하지 않는다. 공간 인덱스는 없고 이웃 제한을 켜면 필터/정렬 비용이 추가된다. 실제 조기 종료·LP 투영 빈도·Python/NumPy 비용·CPU 부하·캐시와 입력 분포 때문에 Runtime 곡선은 Big-O와 다르다. 기존카운터는 LP 내부 쌍 검사를 포함하지 않으므로 새로운 단일 시드 계측을 별도 제시했다.

개발 서버 실측이며 전용CPU 고정 환경은 아니다. 단일 맵의주 분석, 비협조적 인구,10시드, 예비 시나리오2시드, 강체의 평면 원형 거리 근사, 정적 간격 샘플링, 도착시간의 성공 조건부 선택이 한계다. 프레임 관측을 독립 반복으로 세지 않았으며 특수상황의 무충돌 보장을 증명하지 않는다.

## 7. Conclusion

목표 도달과 안전 도달은 크게 달랐고, 알고리즘의 비용·도달률·안전성 사이에 실측 상충 관계가 나타났다. 단일 최고 알고리즘이라는 결론 대신 조건별 표와 불확실성을 제시했다. 후속 연구는 정적 속도 제약, 가속도/추종 동역학을 반영한 회피, 협조/비협조 대조, 독립 시드 확대와 추가 맵 주행이다. 온라인 재탐색은 현재 비교와 분리해 평가해야 한다.
